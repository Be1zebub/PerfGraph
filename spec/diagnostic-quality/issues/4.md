# Issue 4 — Recommendation applicability

## Problem

`src/report/analyzer.ts` creates a recommendation for every warning and uses
generic impact text. This produced CSS, CDN and LCP-element advice that is not
actionable for the tested static page.

## Required change

Every recommendation must reference an observed issue, applicable resource or
metric, and a verification step. Gate image/CSS/JS/CDN advice by evidence;
deduplicate by root cause plus action, not only remediation text prefix.

## Acceptance

No recommendation mentions CSS, image, JavaScript, CDN or cache when the relevant
resource/signal is absent. Recommendations expose evidence and a measurable
success condition.

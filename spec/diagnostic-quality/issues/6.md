# Issue 6 — Deterministic regression fixtures

## Problem

The current tests do not protect against the exact false-positive class found in
the saved result: a minimal page receiving a CSS/render-blocking causal chain.

## Required change

Add fixtures and semantic assertions for: one HTML request, real stylesheet and
image LCP, long JS tasks, CLS clusters, deep request chains, missing Lighthouse,
lab/field conflict and malformed optional data. Prefer invariant assertions over
live-site snapshots.

## Acceptance

The suite fails if a rule emits a node without required evidence, if output views
disagree, or if an absent metric is silently substituted. Tests remain
deterministic and pass without network access.

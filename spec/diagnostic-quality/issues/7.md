# Issue 7 — Agent interpretation contract

## Problem

The skill already describes a useful reading order and ASCII causal graph, but it
cannot compensate for ambiguous evidence and does not prescribe a compact
observed/inferred/impact distinction strongly enough.

## Required change

After report semantics are fixed, update the English skill guidance with a stable
answer template, confidence language, 1–3 chain limit, data-quality caveats and
ASCII degradation graph rules. The agent must state when no causal chain exists,
when a recommendation is generic, and when another run is needed.

## Acceptance

Given the example.com-like report, an agent says the page is healthy, identifies
TTFB as at most a qualified observation, does not invent CSS/image bottlenecks,
and either omits the graph or draws only an evidence-backed chain.

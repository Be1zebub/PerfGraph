# Issue 5 — Output consistency and data quality

## Problem

Agent-facing files can disagree on verdict, metrics or causal interpretation.
The compared outputs also contain corrupted text in `web-perf.md`, while field
values lack visible source and date.

## Required change

Generate all views from one normalized report model. Add explicit lab/field
provenance, collection timestamp, environment, repeat policy and limitations.
Validate text rendering and emit a data-quality section for missing, partial or
conflicting measurements.

## Acceptance

`insights`, `report`, markdown and manifest agree on score/counts/primary metrics.
Non-ASCII or template corruption is caught by tests, and unverified field data
cannot appear as an unqualified measured fact.

# Issue 1 — Resource-aware causal chains

## Problem

`TTFB > 800 ms` сейчас создаёт утверждения про HTML parsing, CSS discovery и
render blocking независимо от состава страницы. Это даёт ложную causal chain
для минимального HTML.

## Required change

Строить каждый промежуточный node только при наличии соответствующего evidence.
Для TTFB без stylesheet evidence допустима цепочка `TTFB → delayed response →
possible LCP impact`, но не CSS/render-blocking. HTML document не считать
render-blocking CSS/JS resource.

## Acceptance

Fixture с одним HTML request и LCP element `p` не создаёт CSS node, render-
blocking node или CSS/image remediation.

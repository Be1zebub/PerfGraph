# Issue 3 — Score and severity calibration

## Problem

Severity node count dominates the verdict. A weak/borderline TTFB warning can
make a green page `moderate`, while multiple derived nodes amplify one signal.

## Required change

Score from measured user-impact metrics and independent root causes. Derived
nodes must not multiply severity. Define explicit rules for green CWV plus
borderline TTFB, Lighthouse overrides, missing data and genuine regressions.

## Acceptance

The example.com-like fixture is `good` or explicitly informational when CWV are
green and no actionable bottleneck is measured. A real LCP/TBT regression remains
`poor` even if Lighthouse data is present.

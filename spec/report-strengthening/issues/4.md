# Issue 4 — Reconcile Network and Lighthouse resources

## Problem

The same run can report 22 render-blocking resources in one section and 19 in
another, without showing whether the difference is source, filtering, or timing.

## Required change

Keep Network and Lighthouse counts/lists separately, compute intersection and
source-only entries, and emit a structured conflict when they disagree.

## Acceptance

Every render-blocking count has a source. A mismatch is visible in data quality
and cannot silently change the causal verdict.

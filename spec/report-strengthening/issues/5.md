# Issue 5 — Qualify CSS/LCP causality

## Problem

Many CSS files are evidence of complexity, not proof that CSS caused all LCP
render delay. The compared tools report 2454 ms savings versus 0 ms savings.

## Required change

Require Lighthouse savings, trace overlap, stylesheet wait timing, or equivalent
evidence before marking CSS as verified. Otherwise use `suspected` and show the
conflicting/absent impact evidence.

## Acceptance

CSS count alone cannot produce a verified LCP root cause or a high-confidence
impact claim.

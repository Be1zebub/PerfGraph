# Issue 6 — LCP element-type-aware remediation

## Problem

Generic LCP remediation suggests image formats and `fetchpriority` even when the
LCP element is a text heading.

## Required change

Select remediation by LCP element/resource type: image, text, video, SVG, or
unknown. Mark irrelevant actions `not-applicable` rather than emitting them.

## Acceptance

Text LCP fixtures never receive image-specific actions. Every emitted action
contains the evidence that made it applicable.

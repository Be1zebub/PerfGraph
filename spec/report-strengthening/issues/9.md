# Issue 9 — Timing anomaly detection

## Problem

Values such as 120000 ms idle time, aggregate request duration above lifecycle
duration, and inconsistent TBT indicate clock-domain or aggregation anomalies.

## Required change

Detect clamping, impossible ordering, and source disagreement. Emit anomalies as
data-quality findings that reduce confidence without automatically changing the
performance score.

## Acceptance

Anomalous timing is visible in report/insights and is never used as direct
user-wait evidence without qualification.

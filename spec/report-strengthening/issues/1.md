# Issue 1 — Separate TBT, busy time and proxy status

## Problem

`perfgraph-3.md` reports TBT 4414 ms while simultaneously saying TBT is
unavailable and busy time 2365 ms is a proxy.

## Required change

Represent metric `value`, `source`, and `status` separately. Emit TBT only when
it is present in validated Lighthouse/IR data; otherwise emit `unavailable` and
show main-thread busy time as a different metric.

## Acceptance

No report or insight can label `busyMs` as TBT. A measured TBT and busy time can
coexist with distinct evidence and provenance.

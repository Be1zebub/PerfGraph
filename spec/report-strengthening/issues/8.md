# Issue 8 — Run environment and variance

## Problem

PerfGraph lab LCP for GitHub is 11095 ms while web-perf lab LCP is 631 ms. The
reports do not expose enough environment context to explain the difference.

## Required change

Persist browser/version, OS, device, viewport, cache state, network/CPU
throttling, headless mode, run count, and per-run variance. Require qualified
language when comparing different environments or single runs.

## Acceptance

Every lab verdict includes collection context. `--runs 3` produces spread and
median/representative values without mixing runs as field data.

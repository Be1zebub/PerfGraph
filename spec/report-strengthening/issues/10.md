# Issue 10 — Stronger agent-facing findings and actions

## Problem

The current skill has `basis` and confidence, but the report does not formally
state whether a finding is verified, suspected, or not applicable, and expected
impact is often generic.

## Required change

Add `findingStatus`, structured edge evidence, applicability, expected-impact
status, and a verification step. Update the English skill and ASCII graph rules
to use these fields.

## Acceptance

Each recommendation has evidence, applicability, expected-impact status, and a
repeat-measurement verification step. The agent never presents inferred impact
as measured user data.

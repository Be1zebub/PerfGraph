# Issue 3 — First-party CDN and vendor ownership

## Problem

Exact-origin comparison classifies `github.githubassets.com` as third-party for
`github.com`, leading to the claim that 99.2% of requests are third-party.

## Required change

Classify same-origin, same-site, configured first-party CDN, external CDN, and
known vendor separately. Allow explicit owned-domain configuration and preserve
the classification reason.

## Acceptance

GitHub-like fixture reports GitHub assets as first-party CDN and does not emit a
third-party-code recommendation when no vendor origin exists.

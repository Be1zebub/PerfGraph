# Issue 6: interpretation contract для skill

## Цель

Зафиксировать, как агент превращает детерминированные артефакты PerfGraph в
полезный инженерный вывод, а не в механический пересказ JSON.

## Входные данные

- `insights.toon` — triage и компактные метрики;
- `report.toon` — summary, issues, chains, recommendations;
- `manifest.toon` — доступность и порядок артефактов;
- `report.md` — fallback для human-readable чтения;
- `graph.toon`, summaries и raw — только для подтверждения конкретной гипотезы.

## Обязательные векторы

1. executive triage;
2. severity/priority;
3. root cause → bottleneck → impact;
4. confidence и evidence;
5. LCP/render path;
6. JavaScript/main thread/TBT/INP signal;
7. network critical path;
8. layout/CLS;
9. third-party overhead;
10. warnings и качество данных;
11. 3–5 действий и план повторной проверки.
12. компактный ASCII causal degradation graph для 1–3 главных chains.

## Правила корректности

- Не считать `Possible INP delay` измеренным INP.
- Не считать Lighthouse Performance единственным итоговым диагнозом.
- Не превращать два issue одной chain в две независимые root causes.
- Не делать сильное утверждение из weak/medium confidence без оговорки.
- Не сообщать expected impact, которого нет в артефакте или который нельзя
  обосновать.
- При failed run сообщать об отсутствии анализа, а не выдавать performance
  verdict.
- ASCII graph строить только из существующих ordered paths в `chains`; не
  добавлять inferred edges.
- Для каждого edge сохранять confidence, если он доступен; отсутствие
  confidence не компенсировать догадкой.
- Ограничивать граф 1–3 приоритетными цепочками и сокращать слишком длинные
  labels без потери метрик.

## Acceptance criteria

- В skill есть явный interpretation workflow.
- Для типичного отчёта агент выдаёт status, 1–3 главные chains, 3–5 действий,
  evidence и ограничения.
- Пример ответа не содержит выдуманных URLs, selectors или metrics.
- Skill различает измеренные метрики и causal impacts.
- Есть инструкция повторить замер после исправления и сравнить те же сигналы.
- В выводе есть ASCII graph или явная отметка, что causal chains отсутствуют.

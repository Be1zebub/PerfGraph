# Issue 1: удалить MCP runtime

## Цель

Убрать MCP как поддерживаемый способ запуска PerfGraph и оставить CLI
единственным runtime interface.

## Затронутые области

- `src/mcp/**`
- `src/cli/mcp.ts`
- `src/index.ts`
- `test/mcp/**`
- `package.json`
- `package-lock.json`

## План изменений

1. Удалить MCP server, handlers, resources, prompts, progress и types.
2. Удалить MCP CLI handler и ветку `mcp` из entry point/help.
3. Удалить `@modelcontextprotocol/sdk` из dependencies.
4. Удалить MCP keyword и MCP-specific package metadata.
5. Удалить MCP tests; добавить/сохранить проверки CLI entry point там, где это
   необходимо.
6. Проверить отсутствие runtime imports MCP через `rg` и TypeScript build.

## Acceptance criteria

- `perfgraph mcp` больше не является валидной командой.
- `src/index.ts` не содержит MCP import или command branch.
- `npm run typecheck` и `npm run build` проходят.
- `npm test` не пытается запускать MCP tests.
- `@modelcontextprotocol/sdk` отсутствует из package manifest и lockfile.
- MCP source не входит в публикуемый пакет.

## Не делать

- Не менять collect/normalize/extract/analyze/report алгоритмы.
- Не переносить незакоммиченные MCP-изменения из текущего рабочего дерева.
